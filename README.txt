Para activar música:

2. Renómbralo `music.mp3`.
3. Abre `index.html`.

La captura permite conservar con mucha fidelidad el aspecto visual de esta sección, pero para convertir TODA la invitación de Canva en HTML editable (textos, contador, mapa, WhatsApp, galería, etc.) necesito capturas de las demás secciones y, si es posible, los archivos originales de imágenes/música.
